1. Why is ReadAllText() suitable here?
  Since there is no requirement that needs processing of lines of the file, we can just read the content of the whole file as a single string instead of an string array.
  ReadAllLines(), or the more specialized ReadAllBytes() are used for more complex use cases, such as but not limited to lexers and tokenizers which requires a more fine grained processing of the contents of the file such as per-line, per-character, or per-byte processing.

The code then reads this file using ReadAllText(), and prints the contents to the console.
